# REX — Retour d'expérience

Ce retour d'expérience doit permettre de refaire le projet de zéro. Il décrit ; il ne contient pas de code. Un fichier par incrément, dans l'ordre de livraison, avec la même structure : objectif, problèmes rencontrés, ce qui a bien marché, ce que j'aurais dû savoir dès le départ, choix techniques et leur raison. Le plan initial (architecture, incréments, environnement) est dans I0.
