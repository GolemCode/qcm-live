# Fichier de démonstration de QCM Live (DEM-01), au format AMC-TXT.
# Questions fictives. Il s'importe d'un coup avec `make demo`, ou par « QCM », puis
# « Importer un fichier AMC », en envoyant le dossier demo/ mis en archive ZIP :
# l'image d'une question est dans demo/images/ (IMP-08).
#
# Ce qu'il montre :
# - question simple au barème par défaut (1 si juste, 0 sinon) ;
# - barème propre à une question ({b=2,m=-0.5}) ;
# - barème par défaut des questions multiples (DefaultScoringM) ;
# - valeur propre d'une proposition (-{-1}) ;
# - « Aucune de ces réponses n'est correcte », ajoutée à chaque question multiple
#   (CompleteMulti, actif par défaut) : juste quand aucune autre ne l'est ;
# - ordre fixe des propositions ([ordered]) ;
# - groupe de questions et son étiquette ([group=geographie]) ;
# - énoncé en deux paragraphes.
# - formule ([[…]], CNT-01), code (bloc verbatim et [|…|], CNT-02), image (!…!, CNT-03)
#   et mise en forme ([*…*], CNT-04).
